# QyestCraft

Minecraft: Java Edition **26.3 + NeoForge** on a standalone Meta Quest, in VR, so a friend with only a Quest can join a NeoForge server running the **mynecraft** mod.

Built on (and audited against upstream):
- [FCL Quest VR](https://github.com/cff1028/FoldCraftLauncher) — Fold Craft Launcher fork with Quest OpenXR support (Java 25, LWJGL 3.4.1, MobileGlues renderer)
- [Vivecraft OpenXR for 26.3](https://github.com/cff1028/VivecraftMod) — Quest port of Vivecraft; QyestCraft builds the **NeoForge** variant
- Sodium for NeoForge 26.3 (beta)

The builds run on GitHub Actions; the phone installer and the mod auto-update manifest are served by GitHub Pages.
