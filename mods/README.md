# Drop mods here

Any `.jar` in this folder goes to your friend's QyestCraft automatically the next time he presses Play.

- **Update your mod:** upload the new jar (Add file → Upload files), and delete the old one.
- **Remove a mod:** delete its jar. It gets removed from his game too.
- Vivecraft and Sodium are added automatically (see `pack/pack.json`), don't put them here.
- Only add jars you trust; whatever is here runs on his headset.
