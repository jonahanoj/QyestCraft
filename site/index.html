QyestCraft

Minecraft Java with Mynecraft, in VR, right on the Quest. Install it from your phone.

  1. Turn on Developer Mode (one time)

    In the Meta Horizon app on your phone: tap the headset icon → your headset → Headset Settings → Developer Mode → on.

    If the switch isn't there, Meta first wants you on a developer team with a verified account (18+): Meta's steps.

  2. Plug your phone into the Quest

    Use a USB-C to USB-C cable that does data (charge-only cables won't work). Open this page in Chrome. Keep the headset on and awake.

  3. Connect

    Pick the Quest from the list. In the headset, choose Always allow and Allow on the USB debugging message.

  4. Install QyestCraft

    Downloads the app (a few hundred MB, use Wi-Fi) and installs it on the headset. Run this again any time to update the app.

  5. Play

    • On the headset: App Library → filter → Unknown Sources → QyestCraft.
    • Allow file access when it asks, then sign in with your Microsoft account (Account → Microsoft; it shows a code to enter at microsoft.com/link on your phone).
    • Tap Install when it offers Mynecraft. Mods update by themselves each time you press Play.

Everything happens in your browser over the cable. The only download is QyestCraft.apk from this site. Source: github.com/jonahanoj/QyestCraft.
